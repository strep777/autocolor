## T1 工程脚手架

- 目录：`backend/app`、`frontend/src`、`tools/`、`tests/`、`data/`。
- 后端 `requirements.txt`（fastapi/uvicorn/sqlalchemy/pydantic-settings/python-multipart/cryptography/httpx）。
- 前端 Vite + React + TS + Tailwind + 路径别名 `@`。
- `.gitignore`、`env.example`、`README.md` 骨架。
- 验收：`uvicorn app.main:app` 返回 `/api/health`；`npm run dev` 出页面。

## T2 后端基础

| 任务 | 文件 | 要点 |
|---|---|---|
| 配置 | `config.py` | env 读取、DATA_DIR 自建、默认值 |
| 数据库 | `database.py` | engine、WAL、SessionLocal、Base、init_db |
| 模型 | `models.py` | 7 表 + 关系 + 级联 |
| Schema | `schemas.py` | Pydantic v2，入参校验 |
| 依赖 | `deps.py` | current_user、require_admin |
| 安全 | `core/security.py` | PBKDF2、token、Fernet、限流 |
| 异常 | `main.py` | 统一错误结构、请求 ID、安全头 |

## T3 认证与用户 ✅ 目标

- 登录/登出/me/改密；Cookie 会话；登录限流。
- 用户管理：列表、创建、改角色/状态、重置密码；不可删除最后一个管理员。
- 验收：A-01~A-08。

## T4 商品与色卡

- 商品 CRUD、色号子资源、分页/搜索/筛选/排序。
- 批量：上架、下架、归档、删除；`ids` 或 `all+filter`。
- 色卡聚合：按色系分组、使用次数、近似色。
- 验收：P-01~P-10。

## T5 颜色科学

- HEX/RGB/HSL/Lab 转换；CIEDE2000；色系归类（12 族）；对比色文字。
- 匹配评分与等级；Top-N。
- 验收：C-01~C-12。

## T6 AI 适配

- Provider 接口；DeepSeek（OpenAI 兼容）、Ollama（/api/chat）。
- 超时、重试 1 次、JSON 提取与修复、schema 校验、非法 id 过滤。
- 默认提示词（skill 格式）双版本；可后台编辑/恢复默认。
- 测试连接、自由分析。
- 验收：R-05~R-09、AI 设置脱敏。

## T7 推荐

- 候选召回（本地 ΔE）→ 可选 AI 重排 → 统一响应。
- 历史记录、反馈（有用/无用）。
- 验收：R-01~R-10。

## T8 设置/统计/上传/导入

- 公开设置、管理设置、AI 配置加密。
- 统计：商品数、色号数、店铺分布、色系分布、近 7 日推荐。
- 上传：魔数、大小、随机名、静态访问。
- 导入：JSON/CSV、dry-run、错误行报告。
- 验收：S-01~S-06、I-01~I-06。

## T9 前端基础

- Tailwind 主题（浅/深）、CSS 变量、字体。
- shadcn 风格组件：Button/Input/Textarea/Select/Dialog/Sheet/Table/Badge/Card/Tabs/Switch/Checkbox/Tooltip/DropdownMenu/Toast。
- API client（fetch、错误归一、401 跳转）、React Query 或自研 hooks（用 @tanstack/react-query）。
- 路由与权限守卫。

## T10 外壳与登录

- 侧边栏（毛玻璃、交通灯、折叠）、顶栏（搜索、主题、用户菜单）。
- 登录页（品牌区 + 表单 + 错误提示）。
- 验收：E-01、E-12。

## T11 工作台

- 4 统计卡、色系分布条、最近商品、快捷入口、空状态。
- 验收：数据与接口一致。

## T12 找色

- 上传/拖拽/粘贴；Canvas 绘制；5×5 放大镜；点击/拖动取色。
- 显示 HEX/RGB/HSL/Lab；复制；手动输入 HEX。
- 参数：材质、仅看相近、数量；本地/AI 切换。
- 结果卡：色块、图、标题、ΔE、价格、店铺、购买链接、AI 理由。
- 验收：E-02~E-03、E-10。

## T25 商品库

- 表格/卡片切换；搜索、筛选、排序、分页。
- 新建/编辑抽屉（含色号编辑器：增删、主色、HEX 取色）。
- 行选择、表头全选、全选筛选结果；批量操作。
- 删除二次确认；空状态。
- 验收：E-04~E-07、E-14。

## T14 色卡库

- 色块网格、按色系筛选、搜索、复制 HEX、查看关联商品。
- 批量选择与删除（管理员）。
- 验收：E-08。

## T15 导入

- 粘贴 JSON/CSV、上传文件、模板下载、dry-run 预览、结果报告。
- 验收：I-01~I-06（前端侧）。

## T16 设置与用户

- AI：提供商、Base URL、模型、Key（脱敏）、温度、超时、提示词编辑/恢复、测试连接。
- 外观：主题、紧凑模式。
- 账户：改密、改显示名。
- 数据：清空示例、导出全部、备份提示。
- 用户管理：列表、新建、角色、禁用、重置密码。
- 验收：E-09、S-01~S-02。
