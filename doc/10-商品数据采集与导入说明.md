- 每个 SKU 的绒面图下载后，取中心 62% 区域裁切为 720×720，作为该商品的展示图（`data/uploads/real/<itemid>.jpg`）。

- 电子色卡受拍摄灯光、屏幕、压缩影响，和实物存在偏差。界面与文档均提示：批量下单前以实物色卡 / 缸样为准。

## 2. 为什么需要登录态

淘宝 / 天猫店铺页对未登录访问返回 **HTTP 200 的登录跳转页**（`login.taobao.com` + `x5secdata`），不是商品 HTML。实测：

- 店铺首页、`category.htm`、`search.htm`、`i/asynSearch.htm` 均跳转登录；
- 无 Cookie 的纯 HTTP 抓取拿不到商品列表；
- 部分店铺分类页即使登录也显示「没有更多商品」，但商品页本身可以正常打开。

因此本项目**不内置绕过登录的爬虫**，真实数据使用“用户自己已登录的浏览器会话”采集：

1. 用 Playwright 启动一个独立的持久化 Edge 配置（`data/browser-profile` 或 `.tmp/taobao-profile`）；
2. 首次以可见窗口打开淘宝，用户手动扫码 / 密码登录；
3. 检测到 `cookie2` 与 `unb` 后，复用该 profile 访问商品页；
4. 从商品页 HTML 内嵌的 SKU JSON 中提取 `"image"` 与 `"name"`，得到每个颜色的图片与名称。

采集频率控制在约 1 请求 / 3 秒，仅用于你自己店铺的商品整理。

## 3. 从商品页到导入 JSON

商品页中的颜色 SKU 形如：

```json
{ "image": "https://gw.alicdn.com/bao/uploaded/...jpg", "name": "白色 23cm*160cm" }
```

清洗规则：

1. 去掉 `尺寸：...`、`23cm*160cm`、`3.5cm`、`12毫米` 等尺寸后缀；
2. 去掉“兽装 / 免剃毛 / 推荐制作 / 弹力毛 / 毛布 / 毛绒”等描述后缀；
3. 跳过“色卡 / 全套色卡”等非布料选项；
4. 同名去重，保留全部有效颜色（后端防御上限 200）；
5. 价格取商品页 `￥xx.x`，入库时 ×100 存分。

导入格式与接口一致（也支持 CSV）：

```json
[
  {
    "title": "暖色系 海鲜毛 鱼毛 兽装毛布",
    "shop_name": "海鲜毛布",
    "shop_url": "https://shop315729358.taobao.com/",
    "product_url": "https://item.taobao.com/item.htm?id=951383650835",
    "external_id": "951383650835",
    "image_url": "/uploads/real/951383650835.jpg",
    "price": 36,
    "material": "海鲜毛",
    "width_cm": 160,
    "status": "active",
    "tags": ["真实采集", "淘宝", "兽装毛布"],
    "colors": [
      { "name": "海盐", "hex": "#B5A888", "is_primary": true },
      { "name": "白对虾", "hex": "#EDE7DC" }
    ]
  }
]
```

- `price` 单位元；也接受 `price_cents`（分）。
- `colors` 也可写成 `"海盐:#B5A888|白对虾:#EDE7DC"`。
- 以 `external_id` 为去重键；没有时按 `title + shop_name`。
- 先「预览检查」dry-run，再「确认导入」。

## 4. 重新采集 / 更新

1. 复制 `env.example` 为 `.env`，按需设置 `ADMIN_PASSWORD`；默认关闭演示数据（`SEED_DEMO=false`）。
2. 启动应用，登录后台。
3. 若是新机器，先安装 Playwright 与浏览器：
   ```bash
   pip install playwright
   python -m playwright install msedge
   ```
4. 用登录态 profile 打开淘宝并手动登录（首次）：
   ```bash
   python tools/collect_taobao.py --login
   ```
   该脚本会保存 `data/browser-profile`，后续可复用。
5. 采集商品：可以用你熟悉的导出工具，或按第 3 节格式生成 JSON；在「数据导入」页预览并写入。
6. 更新已有商品：导入时选“更新已有”，按 `external_id` 覆盖标题、价格、颜色与图片。

> 商品页 DOM 与内嵌 JSON 可能随淘宝改版变化；若解析不到颜色，请以商品页实际 HTML 为准调整正则，不要高频重试。

## 5. 演示数据（可选）

`SEED_DEMO=true` 时，全新数据库会写入 24 条本地演示商品（`source=demo`，标题带“示例”标签，图片为本地 SVG 占位）。默认 `SEED_DEMO=false`，避免把演示数据混入真实商品库。

后台「设置 → 数据与安全 → 清理演示数据」只删除 `source=demo` 的商品，不影响淘宝真实商品与手动导入内容。

## 6. 数据质量规则

1. 标题必须能识别为毛布 / 绒布 / 毛料类；头骨、内胆、材料包、收纳包、补差价等不导入。
2. 每个商品至少 1 个色号，主色只能 1 个。
3. HEX 必须 6 位；系统自动计算 Lab 与色系。
4. 价格允许缺失；同分推荐时优先有价商品。
5. 图片建议使用 `img.alicdn.com` / `gw.alicdn.com` 或本站 `/uploads`；外链失效时前端回退色块占位。
6. 商品下架或店铺改价时，重新导入并选择“更新已有”。
