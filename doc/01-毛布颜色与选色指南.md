# 毛布颜色与选色完全指南

> 文档版本：v1.0 ｜ 适用范围：毛布（法兰绒、珊瑚绒、羊羔绒、短毛绒、长毛绒、摇粒绒等绒面织物）选色、配色、数字化比色
> 读者：本项目的产品、设计、开发、运营与门店选色人员

---

## 1. 毛布是什么：先分清品类，再谈颜色

中文口语里的“毛布”一般指**表面有绒毛的织物**，不是单指羊毛布。不同绒面工艺会让同一个色号呈现完全不同的观感，因此选色前必须先确认品类。

| 品类 | 工艺与手感 | 颜色表现特点 | 选色注意 |
|---|---|---|---|
| 法兰绒（Flannel） | 单面或双面起绒，短密绒 | 哑光、颜色偏“粉”，浅色发灰 | 浅色易被底层基布影响，需看大样 |
| 珊瑚绒（Coral fleece） | 超细纤维起绒，绒条明显 | 反光强、鲜艳色更“跳” | 高饱和色在强光下易显廉价，建议降一档明度 |
| 羊羔绒（Sherpa） | 长绒卷曲，颗粒感 | 同色号会因绒面阴影变深 1~2 个明度 | 米白、燕麦、焦糖最稳；纯白易显脏 |
| 短毛绒 / 水晶绒 | 平绒、光泽高 | 颜色通透、对比强 | 深色易显灰尘，浅色易透底 |
| 摇粒绒（Polar fleece） | 双面摇粒，蓬松 | 色彩均匀、偏运动感 | 适合高饱和撞色，不适合低对比莫兰迪 |
| 长毛绒 / 仿兔毛 | 长绒、有倒顺毛 | 倒顺毛方向会造成明显色差 | 必须统一裁片方向，色卡需标注“顺毛/逆毛” |

**结论：** 选色不能只对照平面色卡，必须以**同品类、同克重、同绒面方向**的实物大样为准。

## 2. 颜色是怎么被描述清楚的

### 2.1 三个基本维度

- **色相（Hue）**：红、橙、黄、绿、青、蓝、紫。决定“是什么颜色”。
- **明度（Lightness/Value）**：深浅。毛布明度差 5% 就足以让人感觉“不是同一块布”。
- **彩度（Chroma/Saturation）**：鲜艳程度。绒面织物的高光会把彩度“洗淡”，所以色卡上很艳的颜色，做成毛布可能发闷。

### 2.2 常用颜色体系

| 体系 | 用途 | 说明 |
|---|---|---|
| RGB / HEX | 屏幕、网页、设计稿 | 本项目以 HEX 为输入，但屏幕色不能直接当布色 |
| HSL | 调色、生成色阶 | 直观，适合前端拾色器与配色计算 |
| CIELAB（L\*a\*b\*） | 色差计算、数字化比色 | 与设备无关，是 ΔE 计算的基础 |
| CIEDE2000（ΔE00） | 判定“看起来差多少” | 比 RGB 欧氏距离更符合人眼 |
| Pantone TCX / TPX | 纺织行业对色 | TCX 为棉布版，TPX 为纸版；毛布建议用 TCX |
| 中国国家标准色卡 | 国内供应链沟通 | 工厂常用“色号 + 缸号”沟通 |

### 2.3 ΔE 的实用阈值（毛布场景）

| ΔE00 | 人眼感受 | 业务含义 |
|---|---|---|
| < 1.0 | 几乎看不出 | 同缸/同批，可视为同色 |
| 1.0 – 2.0 | 仔细看有差异 | 可接受的小缸差 |
| 2.0 – 3.5 | 能看出，但不刺眼 | 常规验收上限（建议） |
| 3.5 – 6.0 | 明显不同色 | 只能做“相近色推荐” |
| > 6.0 | 完全不同的颜色 | 不构成同色替代 |

> 本项目把 **ΔE00 ≤ 3.5** 视为“可直接替代”，3.5–12 视为“相近色”，> 12 只作为配色灵感。

## 3. 毛布选色的完整流程

### 3.1 需求澄清（5 问）

1. **用在哪里？** 服装、家纺、宠物窝垫、汽车内饰、玩具、装饰背景。
2. **卖给谁？** 年龄段、性别倾向、消费层级、地域气候。
3. **什么风格？** 日系自然、北欧极简、复古、国潮、赛博、萌宠。
4. **预算与工艺？** 是否接受染色、印花、压花、复合；起订量与缸差容忍度。
5. **使用环境的光？** 室内暖光、商场射灯、户外日光——同一块布会变三个颜色。

### 3.2 从“参考图”到“颜色候选”

推荐顺序：

1. **提取主色**：从参考图取 3–5 个主色，而不是只取一个点。绒面有高光和阴影，单点取样会偏。
2. **去光污染**：避开反光点、阴影、背景杂物；在图片上多点取样求平均。
3. **校准白平衡**：如果图片偏黄/偏蓝，先在校色工具里用中性灰卡校正，再取样。
4. **映射到布色**：把屏幕色作为“方向”，在实物色卡中找 ΔE 最近的 3 个颜色，再比对大样。
5. **小样验证**：至少 A4 大小，在 D65 标准光源与自然光下各看一次。

### 3.3 配色方法论（可直接落地）

- **60-30-10 法则**：主色 60%（大面积毛布）、辅助色 30%（拼接/包边）、点缀色 10%（纽扣/绣线）。毛布的体量感强，主色一定选耐看的低饱和色。
- **同色系渐变**：同一色相取 3 个明度（如燕麦、奶咖、深棕），最安全、最高级，适合家纺与宠物。
- **邻近色**：色相环相距 30°–60°（如雾蓝 + 灰绿），柔和且有层次。
- **互补色**：相距 180°（如焦糖 + 雾蓝），对比强，点缀用即可；毛布大面积互补容易“俗”。
- **三角配色**：三个等距色相，适合儿童与潮玩，但需降低彩度。
- **无彩色 + 一个强调色**：灰/米/白为主，局部用品牌色，最容易做出高级感。

### 3.4 场景化选色建议

| 场景 | 推荐色系 | 避免 |
|---|---|---|
| 婴童/宠物 | 奶油白、燕麦、雾粉、浅灰蓝 | 高饱和荧光色、深黑（显脏且压抑） |
| 家居沙发/毯 | 驼色、焦糖、灰绿、雾霾蓝、暖灰 | 纯白（易脏）、大红（难搭配） |
| 秋冬服装 | 深咖、酒红、墨绿、藏青、炭灰 | 高明度冷色（显单薄） |
| 春夏薄绒 | 奶油黄、浅杏、薄荷、天蓝 | 厚重深色 |
| 潮玩/文创 | 高饱和撞色、荧光点缀 | 大面积低对比灰 |
| 汽车内饰 | 黑、深灰、米棕 | 高反光浅色（眩光） |

## 4. 绒面织物的“颜色陷阱”

1. **同色异谱（Metamerism）**：两个在屏幕/一种灯下相同的颜色，换光源后不同。解决：指定光源（D65）并看实物。
2. **倒顺毛**：长毛绒顺着摸显亮、逆着摸显暗，同一块布能有 1–2 个明度差。裁剪必须同向。
3. **绒面高光**：珊瑚绒、水晶绒反光强，深色会“发白”，浅色会“发光”。选色时降低一档彩度更稳。
4. **缸差**：同色号不同染缸有差异，需约定 ΔE 上限与缸号追溯。
5. **屏幕色 ≠ 布色**：手机拍照自动美颜/增艳，显示器色域与亮度都不准。数字化只能做“初筛”，最终以大样为准。
6. **底色渗透**：浅色毛布会透出基布颜色，尤其薄型法兰绒；打样时需同基布。
7. **色牢度**：深色（尤其红、蓝）需关注水洗、摩擦、日晒牢度；宠物用品优先选高牢度。

## 5. 数字化选色：本系统的处理方式

### 5.1 从图片取色

- 支持上传 JPG/PNG/WebP，浏览器本地解码，不上传原图（隐私友好）。
- 放大镜取色：以点击点为中心取 5×5 像素平均，降低噪点影响。
- 同时显示 HEX、RGB、HSL、Lab，方便与工厂沟通。
- 支持系统级吸管（浏览器支持 EyeDropper API 时）直接吸取屏幕任意位置。

### 5.2 颜色匹配算法

1. sRGB → 线性 RGB → XYZ（D65）→ CIELAB。
2. 用 **CIEDE2000** 计算输入色与每个毛布色号的色差。
3. 相似度分数：`score = 100 × exp(-(ΔE / 18)²)`，并给出“可替代 / 相近 / 灵感”三级标签。
4. 可选加权：同色系加分、同材质加分、在售状态优先、价格区间过滤。
5. 返回商品图、色号、ΔE、相似度、购买链接。

### 5.3 拍照/取样规范（给用户的操作建议）

- 在**白天北向窗边**或 D65 灯箱下拍摄，关闭闪光灯与美颜。
- 画面里放一张白纸或灰卡，方便校正白平衡。
- 镜头与布面垂直，距离 30–50cm，避免阴影。
- 至少拍 3 张：顺毛、逆毛、自然平铺。
- 屏幕亮度调到 50% 左右，关闭夜间模式。

## 6. 术语表

| 术语 | 含义 |
|---|---|
| 色相 / 明度 / 彩度 | 颜色的三个基本属性 |
| ΔE00 | CIEDE2000 色差，数值越小越接近 |
| 同色异谱 | 不同光源下颜色匹配关系改变 |
| 缸差 | 不同染缸/批次造成的色差 |
| 倒顺毛 | 绒毛有方向性，不同方向观感不同 |
| 克重（GSM） | 每平方米克重，影响垂坠与颜色厚度感 |
| 色牢度 | 耐水洗、耐摩擦、耐日晒的能力 |
| TCX | Pantone 纺织棉布色卡 |
| D65 | 常用标准光源，近似正午日光 |
