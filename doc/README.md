## 约定

- 文档中的接口、字段、颜色值以代码为准；发现不一致时先改文档再改代码（或反之），不允许长期漂移。
- 所有金额单位为「分」（`price_cents`）；所有色值为 6 位大写 HEX（`#RRGGBB`）。
- 颜色计算统一 D65 光源、2° 观察者、sRGB 输入。
