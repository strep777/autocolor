# UI/UX 设计规范（macOS 风格）

> 目标：简洁、优雅、对新手友好。少参数、强反馈、可预期。
> 技术：Tailwind CSS 3 + shadcn/ui + Radix + Lucide + intro.js

---

## 1. 设计原则

1. **一屏一件事**：每个页面只有一个主行动（找色页 = 取色，商品页 = 管理）。
2. **先默认、后微调**：筛选默认折叠，推荐默认 8 条，参数都有合理默认值。
3. **可见即所得**：颜色一律同时给色块 + HEX；危险操作红色且二次确认。
4. **系统感**：使用 macOS 的层级（侧边栏/内容/检查器）、材质（vibrancy）、圆角与阴影，而不是“网页模板感”。
5. **可撤销的错觉**：删除前确认、批量前显示数量、AI 失败自动回退并提示。

## 2. 视觉系统

### 2.1 色板（浅色）

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#F5F5F7` | 页面背景（macOS 窗口灰） |
| `--surface` | `rgba(255,255,255,0.72)` | 卡片/侧边栏（毛玻璃） |
| `--surface-solid` | `#FFFFFF` | 弹窗、下拉 |
| `--text` | `#1D1D1F` | 主文字 |
| `--text-secondary` | `#6E6E73` | 次要文字 |
| `--border` | `rgba(0,0,0,0.08)` | 分隔线 |
| `--accent` | `#0A84FF` | 主行动（macOS 蓝） |
| `--accent-hover` | `#0071E3` | |
| `--danger` | `#FF3B30` | 删除/危险 |
| `--success` | `#34C759` | 成功 |
| `--warning` | `#FF9F0A` | 警告 |

### 2.2 色板（深色）

| Token | 值 |
|---|---|
| `--bg` | `#1C1C1E` |
| `--surface` | `rgba(44,44,46,0.72)` |
| `--surface-solid` | `#2C2C2E` |
| `--text` | `#F5F5F7` |
| `--text-secondary` | `#98989D` |
| `--border` | `rgba(255,255,255,0.10)` |
| `--accent` | `#0A84FF` |

> 颜色通过 CSS 变量注入，主题切换只改 `data-theme`，组件不写死颜色。

### 2.3 字体

```
font-family: -apple-system, BlinkMacSystemFont, "SF Pro Text", "SF Pro Display",
  "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Segoe UI", sans-serif;
```

| 层级 | 字号/行高/字重 |
|---|---|
| 大标题 | 28/36, 700, letter-spacing -0.02em |
| 页面标题 | 22/30, 600 |
| 卡片标题 | 15/22, 600 |
| 正文 | 14/22, 400 |
| 辅助 | 12/18, 400, secondary |
| 等宽（HEX/Lab） | 13/20, `ui-monospace, SFMono-Regular, Menlo` |

### 2.4 圆角、阴影、间距

- 圆角：卡片 16px，按钮 10px，输入 10px，弹窗 18px，色块 50%（圆形）/8px（方形）。
- 阴影：`0 1px 2px rgba(0,0,0,.04), 0 8px 24px rgba(0,0,0,.06)`；弹窗 `0 24px 64px rgba(0,0,0,.18)`。
- 间距基数 4px：4/8/12/16/24/32/48。
- 分隔线 1px，透明度 8%。

### 2.5 动效

- 时长 150–220ms，缓动 `cubic-bezier(0.25, 0.1, 0.25, 1)`。
- 仅对透明度、位移 ≤8px、缩放 ≤2% 做动画；尊重 `prefers-reduced-motion`。

## 3. 布局

### 3.1 应用外壳

```
┌──────────────────────────────────────────────────────────────┐
│ ● ● ●   毛布选色 · 色研所                      ⌘K   ?   ◐  │  ← 标题栏 44px
├───────────────┬──────────────────────────────────────────────┤
│  ⌂ 工作台      │  页面标题                          [主按钮]  │
│  ◉ 找色        │  ──────────────────────────────────────────  │
│  ▦ 商品库      │                                              │
│  ◫ 色卡库      │   内容区（最大宽 1280，居中，24px 内边距）    │
│  ↥ 导入        │                                              │
│  ⚙ 设置        │                                              │
│  👤 用户       │                                              │
│               │                                              │
│  [新手指引]    │                                              │
│  admin ▾      │                                              │
└───────────────┴──────────────────────────────────────────────┘
```

- 侧边栏 232px，`backdrop-blur(20px)`，半透明；选中项为 8% 蓝色底 + 蓝色图标。
- 标题栏交通灯仅装饰（红黄绿圆点），保留 macOS 记忆点。
- 内容区滚动，侧边栏固定。

### 3.2 找色页（核心）

```
┌────────────────────────────┬─────────────────────────────────┐
│  1 上传参考图               │  当前颜色                        │
│  ┌──────────────────────┐  │  ● #C8A27A   RGB 200,162,122    │
│  │                      │  │  HSL 30° 41% 63%  Lab 69.7 14.9 27.3 │
│  │      图片画布         │  │  [本地匹配] [AI 分析]  ← 分段控件 │
│  │   （滴管放大镜）      │  │                                 │
│  └──────────────────────┘  │  筛选 ▾（材质/店铺/价格/仅可替代）│
│  [重新上传] [系统吸管]      │                                 │
│                            │  ┌─────┐ ┌─────┐ ┌─────┐        │
│  最近取色 ●●●●●            │  │商品 │ │商品 │ │商品 │        │
│                            │  └─────┘ └─────┘ └─────┘        │
└────────────────────────────┴─────────────────────────────────┘
```

- 左栏 5/12，右栏 7/12；≥1280 并排，<1024 上下堆叠。
- 画布：棋盘格背景（透明图），滚轮缩放 50%–800%，拖拽平移，双击复位。
- 滴管：点击后显示 96px 圆形放大镜（跟随鼠标），中心十字 + 5×5 平均；松开确认。
- 结果卡片：商品图 4:3、色块 + 色号、相似度条、ΔE 标签、购买按钮（外链 `noopener`）。

### 3.3 商品库

- 顶部：搜索框（⌘K 聚焦）、筛选 chips、视图切换（表格/卡片）、`+ 新增商品`。
- 表格：复选框列、商品（缩略图+标题）、色号（最多 4 个色点 +N）、店铺、材质、价格、状态、操作。
- 表头复选框 = 全选当前页；选中后出现浮动操作条：“已选 12 项 · 全选筛选结果 · 批量上架 · 批量下架 · 删除”。
- 行悬停出现“编辑/删除”，点击行打开右侧详情抽屉。

### 3.4 色卡库

- 以色块为主的网格：每个「店铺色」一张卡（色块 142px、名称、HEX、店铺、商品数）。
- 同一店铺同名颜色只保留一张；不同店铺同色分别展示，卡片底部标注店铺名；支持按商店/按色号排序。
- 支持按色系 chip 过滤、色名/HEX/店铺搜索；输入 3/6 位 HEX 时按色差排序并显示 ΔE，详情显示与搜索色的色差、Lab、来源商品与购买链接，可跳转找色。

### 3.5 设置

- 左侧二级导航（AI / 外观 / 账户 / 数据），右侧表单。
- AI 页：提供商分段控件、Base URL、API Key（密码框 + 显示/隐藏）、模型、温度滑杆、超时、提示词编辑器（等宽、可恢复默认）、测试连接。
- 保存按钮固定在底部右侧，未修改时禁用。

## 4. 组件规范（shadcn/ui 映射）

| 场景 | 组件 | 关键行为 |
|---|---|---|
| 主/次/危险按钮 | `Button` | 高度 36，图标 16，loading 时禁用并转圈 |
| 输入 | `Input` / `Textarea` | 聚焦蓝色 3px 光环；错误红边 + 文案 |
| 选择 | `Select` | Radix，键盘可操作 |
| 弹窗 | `Dialog` | 标题 + 描述 + 底部右对齐按钮；Esc 关闭 |
| 确认 | `AlertDialog` | 危险操作必须用，文案包含对象名 |
| 提示 | `sonner` Toast | 成功 2s、失败 4s，右上角 |
| 表格 | 原生 table + Tailwind | 斑马纹不用；行悬停 4% 灰 |
| 徽章 | `Badge` | 状态：在售绿、下架灰、ΔE 分级 |
| 骨架 | `Skeleton` | 列表加载 6 行 |
| 空状态 | 自定义 | 图标 + 一句解释 + 主行动按钮 |
| 抽屉 | `Sheet` | 商品详情，宽度 480 |

## 5. 新手引导（intro.js）

- 入口：侧边栏底部“新手指引”按钮（常驻），首次登录弹一次“是否开始引导？”（localStorage 记忆）。
- 配置：`showProgress: true`、`showBullets: false`、`exitOnOverlayClick: false`、`nextLabel: 下一步`、`prevLabel: 上一步`、`doneLabel: 开始使用`、`skipLabel: 跳过`。
- 步骤（按当前路由动态）：

| # | 目标元素 | 文案 |
|---|---|---|
| 1 | `[data-intro=sidebar]` | 这里是主导航：找色、商品库、色卡库、设置。 |
| 2 | `[data-intro=find-color]` | 点击“找色”，上传客户参考图。 |
| 3 | `[data-intro=upload]` | 支持 JPG/PNG/WebP，图片只在浏览器本地处理。 |
| 4 | `[data-intro=canvas]` | 在图片上单击取色，放大镜会取 5×5 平均色。 |
| 5 | `[data-intro=color-value]` | 这里显示 HEX/RGB/Lab，可直接复制给工厂。 |
| 6 | `[data-intro=mode]` | “本地匹配”快且离线；“AI 分析”会给搭配理由。 |
| 7 | `[data-intro=results]` | 结果按色差排序，点击商品可跳转购买。 |
| 8 | `[data-intro=guide-btn]` | 随时可再点这里重看引导。 |

- 引导进行时禁止页面滚动（intro.js 自带），结束后聚焦主内容。
- 移动端自动精简为 4 步。

## 6. 交互细节

- **快捷键**：`⌘/Ctrl + K` 打开全局搜索/命令面板；`Esc` 关闭弹窗；`/` 聚焦搜索。
- **复制**：点击 HEX 复制并 Toast “已复制 #C8A27A”。
- **表单**：未保存离开时提示；提交按钮 loading；成功后关闭并刷新列表。
- **错误**：网络错误显示“无法连接服务器，请确认服务已启动”，并提供重试。
- **空状态**：商品库为空 → “还没有商品，先导入淘宝数据或新增一个”。
- **权限**：非 admin 隐藏管理入口（而非禁用），直接访问路由则显示 403 页。
- **免责声明**：找色结果下方固定一行小字“屏幕与实物存在色差，最终以实物大样为准”。

## 7. 无障碍与适配

- 所有交互元素可 Tab 聚焦，焦点环可见；图标按钮有 `aria-label`。
- 对比度：正文 ≥ 4.5:1，辅助文字 ≥ 3:1。
- 色彩不作为唯一信息载体（ΔE 同时给数字与文字等级）。
- 断点：`sm 640` / `md 768` / `lg 1024` / `xl 1280`；移动端侧边栏变为底部 Tab 或抽屉。
- 图片 `alt` 使用商品标题；装饰图 `alt=""`。

---

## 8. 文案规范

- 简洁、动词开头：“保存设置”“新增商品”“开始匹配”。
- 不用技术黑话：用“色差”而不是“ΔE00 距离”（数字旁可标注 ΔE）。
- 上传错误文案给解决方案：“磁盘空间不足，请清理空间后重试”；格式错误提示支持 JPG/PNG/WebP。
- 中英文之间加空格，数字与单位间加空格（如 `320 gsm`）。
